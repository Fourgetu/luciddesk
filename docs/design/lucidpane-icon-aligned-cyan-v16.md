# LucidDesk 应用图标

当前图标源文件为 [lucidpane-icon-aligned-cyan-v16.png](lucidpane-icon-aligned-cyan-v16.png)，运行资源为 [lucidpane.ico](../../app/assets/lucidpane.ico)。EXE、窗口、托盘及关于页使用同一图标体系，源文件保留既有名称。

## 视觉规范

图标由左侧长面板和右侧上下两个面板组成，使用蓝青渐变、圆角与透明背景。调整资源时保持既定构图、配色及透明通道。

源图画布为 1254×1254。图形具有少量像素级比例差异，应以源图为准，不依据旧生成提示词重新推导几何尺寸。

## 资源导出

导出时裁去多余透明留白，将主体居中放入方形画布，使最长边占画布的 87.5%，再按用途缩放和转换格式。不得直接修改源图来适配某个图标尺寸。

资源尺寸、生成方式与检查入口见[应用资源说明](../../app/assets/README.md)。产品名称及数据目录兼容规则见[品牌规范](../brand.md)。
