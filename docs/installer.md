# LucidDesk 安装与更新

安装包文件名为 `LucidDesk-<版本>-windows-x64-setup.exe`，使用 Inno Setup。它负责程序部署、快捷方式和卸载入口，适合需要常规 Windows 安装体验的用户。便携使用方式见[便携版说明](portable.md)，启动后的功能与操作见[使用指南](usage.md)。

## 首次安装

运行安装包，选择安装范围和目录，再按向导完成安装。

| 安装范围 | 默认目录 | 权限与入口 |
| --- | --- | --- |
| 仅为当前用户安装 | `%LOCALAPPDATA%\Programs\LucidDesk` | 无需管理员权限，快捷方式和卸载入口属于当前用户 |
| 为所有用户安装 | 系统 Program Files 下的 `LucidDesk` | 需要管理员权限，快捷方式和卸载入口跟随所有用户安装范围 |

可以选择其他目录。安装到 Program Files 时选择所有用户安装；程序日常运行无需管理员权限，各账户分别使用自己的用户数据。

开始菜单快捷方式自动创建，桌面快捷方式首次默认不勾选，升级时沿用之前的任务选择。交互式安装完成页可选择启动 LucidDesk；静默安装不自动启动程序。

安装目录包含 `luciddesk.exe`、配套 `luciddesk_desktop.dll`、`installed` 标记及说明文件。请保留配套文件，不单独替换其他版本的 DLL。若目标目录含有 `portable` 文件，安装器会要求选择其他目录，以免改变便携版的数据保存方式。

## 配置与数据

默认配置、面板布局和备份保存在 `%LOCALAPPDATA%\LucidDesk`，不随程序目录变化。指定数据目录环境变量时优先使用指定路径。名称和目录规则见[品牌规范](brand.md)。

普通更新保留这些数据。安装器不会将收纳到分组中的桌面文件移动到安装目录，也不会把真实桌面文件作为卸载目标。重要布局可先在“设置 → 备份与恢复”导出；该备份保存配置与引用，不包含真实文件内容。

## 更新与切换安装范围

1. 打开“设置 → 关于”，点击“检查更新”。更新检查由手动操作触发。
2. 点击“打开更新页面”，查看 Release 说明并下载对应安装包。
3. 退出 LucidDesk，运行新版安装包完成升级；也可以按安装器提示请求程序正常退出。
4. 完成后启动程序，确认版本、面板布局和配置。

安装器沿用已有安装范围及目录，并检查卸载记录和目标 EXE 的版本，发现高于待安装版本时拒绝降级。更换安装范围时，先卸载旧安装并保留配置，再选择所需范围重新安装；不要通过同时保留两套安装来切换。

普通 ZIP 用户可以改用安装包，程序仍按相同规则查找 LocalAppData 数据。便携版应使用便携 ZIP 更新并保留 `data`，不要将安装包覆盖到便携目录。MSIX 的更新由 Windows 包部署机制管理，不适用本页的 Inno 安装流程。

### 程序正在运行时

安装或卸载前会检查 LucidDesk 是否运行。交互提示默认不自动同意关闭；确认后请求正常退出，等待主进程结束，再检查 Explorer 中的桌面组件和目标 DLL 是否已释放。

拒绝关闭、程序无响应、无法确认组件状态或组件仍占用时，操作会在覆盖或删除程序文件前停止。程序尚在启动或无法找到其托盘窗口时，可能需要手动退出后重试。安装器不强制结束 LucidDesk，也不自动重启 Explorer。

安装版从程序目录加载桌面 DLL。组件检查不只判断目标文件能否写入，还检查 Explorer 实际加载的组件，因此其他目录中仍在使用的组件也可能阻止安装。

## 卸载与数据保留

从 Windows 的应用卸载入口启动卸载。若程序仍在运行，先完成正常退出和组件释放检查，再确认卸载。

确认窗口默认勾选“保留用户配置”。需要清除设置时取消勾选并确认，卸载完成后才清理以下目录：

- 执行卸载账户的 `%LOCALAPPDATA%\LucidDesk`。

清理范围包括其中的配置、面板布局和备份。取消卸载不会删除配置；自定义数据目录、便携版 `data`、真实文件及其他账户的数据不在清理范围。所有用户安装不等于卸载时清理所有账户；使用另一管理员账户执行卸载时，也不能据此认为原使用者的数据已删除。

如果确认窗口的配置选项无法创建，默认保留数据。部分数据删除失败时会提示目录，不能将程序已卸载等同于数据已全部清除。

### 快捷方式与 Windows 列表

开始菜单和安装器创建的桌面快捷方式由 `[Icons]` 及 Inno 原生卸载日志管理。卸载不会自定义扫描整个开始菜单。

此外，卸载检查当前账户桌面顶层的 `.lnk`；所有用户安装还检查公共桌面顶层。只清理目标确实指向本次安装目录中 `luciddesk.exe` 的链接，包括改名或复制后的链接。不会递归扫描桌面子目录或遍历目录联接，其他安装目录和便携版的链接保留。

应用及安装快捷方式使用固定 AppUserModelID `Yuchen95.LucidDesk`，不随版本或安装路径变化。它不同于用于升级和卸载识别的 Inno AppId，也不意味着 Windows 应用列表备份记录由安装器管理。

卸载后会通知 Shell 刷新相关目录与 AppsFolder。搜索结果可能延迟更新；安装器不删除 AppListBackup、App Resolver 等系统数据，也不清除其他应用缓存或用户固定项。

## 命令行安装与卸载

以下示例中的版本和路径需替换为实际值。静默安装仍执行运行状态、降级和组件占用检查。

```powershell
# 当前用户静默安装；允许请求 LucidDesk 正常退出
& '.\LucidDesk-<版本>-windows-x64-setup.exe' /CURRENTUSER /VERYSILENT /SUPPRESSMSGBOXES

# 所有用户安装，需要管理员权限
& '.\LucidDesk-<版本>-windows-x64-setup.exe' /ALLUSERS
```

| 参数 | 含义 |
| --- | --- |
| `/CURRENTUSER`、`/ALLUSERS` | 指定安装范围 |
| `/VERYSILENT /SUPPRESSMSGBOXES` | 静默安装并抑制提示，正常关闭请求自动确认 |
| `/NOCLOSEAPPLICATIONS` | 禁止安装器请求自动关闭；应用运行时需先手动退出 |
| `/DELETEUSERDATA` | 静默卸载时显式清理上述用户数据目录 |
| `/KEEPUSERDATA` | 静默卸载时保留配置，与删除参数同时传入时优先 |

静默卸载默认保留配置，数据参数仅用于静默卸载。交互卸载按确认窗口中的选择处理。自动关闭只请求正常退出，无响应时仍会停止操作。

## 常见问题

| 提示或现象 | 处理方式 |
| --- | --- |
| 程序尚未退出 | 从托盘退出，等待进程结束后重试；安装器不会强杀进程 |
| Explorer 桌面组件仍占用 | 退出 LucidDesk 后稍候；持续无法释放时，手动重启 Windows 资源管理器或注销后再操作 |
| 无法确认组件释放 | 保留错误信息，检查会话与权限；不要通过删除或改名 DLL 绕过检查 |
| 检测到较新版本 | 使用相同或更新版本安装包，避免覆盖为旧版本 |
| 目标目录包含便携版 | 选择独立安装目录，或改用便携 ZIP 更新 |
| 卸载后搜索仍显示入口 | 等待 Shell 刷新，并区分实际快捷方式、固定项和系统备份记录 |

安装包及发布 ZIP 均附带 SHA256 校验文件。安装内容中的 `build.json` 记录源码版本、Git 修订、未提交修改状态及 EXE/DLL 校验值。报告安装问题时附上包版本、安装范围、错误提示和日志，便于核对具体产物。

卸载会核对并移除属于当前安装的当前用户 Run 自启登记，无论是否保留配置；其他安装和其他账户的登记不会删除，Windows 的 StartupApproved 状态不会修改。
