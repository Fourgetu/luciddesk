# LucidPane 项目介绍

LucidPane 是开发中的 Windows 桌面图标分组工具。你可以将桌面项目收纳到分组面板中，通过拖动、折叠、吸附和外观设置整理工作区域。

分组保存的是项目引用。收纳、移出和删除分组不会搬动或删除原文件；通过图标的 Shell 菜单执行重命名、删除等操作，则会作用于真实项目。

## 当前功能

- 将桌面项目拖入分组，在分组间调整归属与顺序，拖回桌面取消收纳。
- 移动、缩放和折叠分组，配置自动收起、锁定与置顶行为。
- 调整主题与背景材质，通过设置窗口管理分组外观。
- 打开项目，调用 Explorer 图标菜单，在分组内使用 F2 重命名。
- 通过托盘显示分组、新建分组、打开设置或退出。
- 保存分组配置与成员归属，下次启动时读取。

## 运行方式与边界

当前主线只提供“Explorer 原生桌面 + 自绘分组面板”这一种运行方式。未收纳图标由 Explorer 显示，已收纳项目由 LucidPane 面板显示；程序退出时撤销桌面显示映射。

项目主要在 Windows 11 x64 上开发。桌面集成依赖经过校验的系统组件版本，不代表兼容所有 Windows 版本或更新。当前还不是面向普通用户的稳定发行版。

云母、云母 Alt 等外观使用系统壁纸画刷与色调组合，不等同于完整原生 Mica 控制器。系统材质不可用时使用普通背景。
