# 新分组预览：实现与验证记录

2026-09-07。对应重设计方案的视觉原型和布局原型阶段。

2026-09-08 更新：本文记录原来的独立预览。默认启动已改为“整体隐藏 + 自绘桌面”，独立预览通过 `--preview` 启动，详见 [新桌面实现](redrawn-desktop-implementation.md)。

## 已实现

- 默认启动独立预览，原生桌面继续显示；不进入旧接管/恢复路径，不修改自动排列设置。
- 两个初始分组，可新建更多分组。背景、标题和图标作为完整窗口一起移动。
- Direct2D 绘制预乘 alpha 内容，DirectWrite 排版，WIC 缓冲上传到 D3D11 交换链，通过 DirectComposition 呈现。
- 非 layered 窗口支持亚克力 / 云母，菜单即时切换并按分组保存。新分组默认亚克力，已有分组保留存储的材质。
- 亚克力改为独立的 HostBackdropBrush 背景采样和染色层（底部 Composition target），内容交换链保持在顶部；不使用随窗口激活状态变化的 DWMSBT_TRANSIENTWINDOW。云母继续使用系统背景。
- 内容层空白区域 alpha 为零；不支持材质时使用实色底。HostBackdropBrush 仍受系统透明设置和电源策略控制；分组失焦不再触发应用层的亚克力回退。
- 半透明背景、细边界和圆角；图标/缩略图直接取自 Shell，原颜色不随背景透明度变化。
- 从系统读取图标标题字体；支持窗口 DPI 变化。当前图标布局基线仍为 48 DIP，资源请求 96px。
- 在后台读取桌面命名空间与图片，主线程处理输入和绘制。列表尚未加载时显示加载提示。
- 同一网格算法驱动绘制、命中、滚动和键盘导航；缩放自动换行、滚动位置钳制、折叠与展开。
- 预览窗口之间的单项目拖放、组内排序，以及按名称排序；事务保存归属与顺序，失败回退。
- 命中目标检查实际顶层窗口，避免把图标误放入被其他窗口遮挡的分组。
- 打开操作通过 Shell 执行。预览不会把拖动转成真实移动、复制或删除。
- 正常启动不再产生调试控制台。

## 验证证据及范围

1. 自动测试验证 100%、150%、200% 的离屏结果：原生材质对应的内容背景 alpha 为零，回退背景为不透明，合成前的图标中心像素
   保持原 RGBA，圆角外 alpha 为零。此测试不等于各屏幕上完整的视觉一致性测试。
2. 网格测试覆盖缩放后的列数、带滚动的命中坐标和滚动上界。
3. 内存 SQLite 测试覆盖跨组往返、身份不变、顺序持久化、清单对账与不存在目标的拒绝。
4. 通过 Windows 窗口捕获观察了真实 Shell 项目和空分组。确认已显示完整内容面、真实图标和
   细边界。工具最初未列出 tool-window 形式的预览，改为独立普通应用窗口后可正常发现。
5. 跨窗口鼠标拖动自动化受到工具坐标不能超出源窗口的限制，未完成端到端鼠标验证。
   分组归属测试通过不能替代这项实机验收。
6. 工作区测试有 42 项通过；旧原生方案的 2 项 Explorer 集成测试受沙箱访问限制，最终运行中显式跳过。
   原生桌面读取测试的提权重跑被自动审批拒绝，没有绕过该限制。
7. `cargo clippy --workspace --all-targets -- -D warnings` 及 release 构建通过。

材质接口参考：[Microsoft DWM_SYSTEMBACKDROP_TYPE](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)。官方支持起点为 Windows 11 build 22621。
本次实机窗口捕获确认新合成路径有背景材质和清晰图标；菜单切换的自动鼠标验证被实时用户输入打断，尚未完成完整实机往返验证。

不把曾经失败的启动探测、被用户输入中断的动作或自动化工具拒绝的动作算作成功。

## 运行

### 交互修正

- 菜单进一步替换为 WinUI 3 风格的自定义 Composition 浮层（并非 WinUI 3/XAML 控件）：圆角亚克力、细边线、系统阴影、统一行高、选中高亮和约 120ms 淡入。关闭系统客户区动画时直接显示。
- 主菜单保留分组操作、自动收起和退出；材质移入侧边子菜单，支持点击、悬停或右方向键展开。上下选择、Enter/Space 执行、Esc/左键返回，以及失焦关闭由浮层处理。屏幕边缘自动翻转或限制位置。
- 实机已观察主菜单及侧边材质子菜单正常打开；完整键盘路径尚未验收。自定义浮层尚未实现 UI Automation 菜单项语义，不能声称与原生 MenuFlyout 的无障碍支持等同。

- 移动分组时，按当前可见边缘吸附：固定 5px 物理像素间隔（不随 DPI 放大），14 DIP 吸附阈值，邻近分组顶部/底部或左右边缘对齐，保持宽高不变；松开后沿原布局路径保存位置。
- 每组菜单增加“自动收起”开关，默认关闭。悬停约 120ms 展开，离开约 600ms 收起，使用已有动画；拖动源分组持有鼠标捕获及菜单嵌套操作时暂停自动折叠。关闭开关保留当前展开/收起状态，仍可手动切换。
- 数据库升级至版本 6，新增独立分组行为表；旧分组默认关闭，新设置随工作区事务保存。测试覆盖旧版本迁移、连续保存后的开关恢复、负坐标屏幕下的吸附间隔/对齐和尺寸保持。
- 本次存储与应用测试共 23 项通过；完整实机拖动吸附和悬停往返尚未验收。

- 分组菜单改为原生 owner-draw 深色菜单：背景材质标题、当前材质勾选、分组操作和退出分区；统一字体/行高，圆角选中高亮，移除顶部预览说明。按钮打开时对齐右下方，右键打开时仍以鼠标位置为锚点；保留原生菜单文字、键盘导航和自动屏幕边界调整。
- 菜单测量/绘制由永久 subclass 处理，避免窗口库在菜单嵌套消息循环中暂时解绑回调导致绘制失败。已实机观察深色菜单排版与锚点，键盘测试因焦点切换未完成。

- 收起/展开使用约 200ms 的 cubic ease-out 高度过渡，箭头同步变形，内容沿窗口边缘裁切。连续点击从当前高度反向运行；动画结束停止 16ms 定时器。系统禁用客户区动画时直接切换。手动移动/缩放前完成过渡，避免保存中间高度；动画帧不写数据库。
- 自动测试覆盖折叠中断、反向起点连续和最终高度；连续画面的流畅度仍需实机验收。

- 持续亚克力已在实机观察：激活另一个分组后，原分组继续呈现模糊背景及染色，图标和文字保持清晰。没有抢焦点处理。系统关闭透明效果的实际设置切换未测试。
- 接口参考：[CreateHostBackdropBrush](https://learn.microsoft.com/en-us/uwp/api/windows.ui.composition.compositor.createhostbackdropbrush)。该接口采样窗口绘制前的背景，透明程度受系统设置和电源策略控制。

- 为预览窗口启用双击消息：单击选中，双击或 Enter 通过 Shell 打开。已在实机双击打开“主文件夹”。
- 单独拦截非客户区尺寸计算，避免窗口库在材质初始化/折叠的重入消息中恢复系统边框；同时关闭 DWM 额外边线。最终窗口捕获已观察到顶部重叠边框消失。
- 标题按钮使用矢量折叠箭头和三点图案，提供 28 DIP 点击区域和悬停反馈；菜单打开前释放模型借用。
- 拖动预览改为独立的逐像素 alpha 分层窗口，替代有黑框问题的 common-controls 图像。预乘 BGRA 双线性缩放保持透明边缘，按源图标尺寸和 DPI 显示；保留鼠标按下时相对图标的位置，避免开始拖动时跳动。窗口不抢焦点，先提交像素再显示，移动时仅更新坐标。
- 释放、失去捕获、取消或 Esc 清除预览。Esc 在拖动中只取消拖动。透明像素、半透明边缘和缩放尺寸的回归测试通过。
- 尚未通过自动化捕获拖动中的连续画面，不将拖动图像的视觉效果记作已完成实机验收。

```powershell
cargo run -p lucidpane --release
# 或仅预览一个测试目录
cargo run -p lucidpane --release -- --preview "E:\Project\LucidPane"
```

右上角省略号/右键打开分组菜单，箭头或双击标题折叠。按 Esc 退出预览。
默认桌面引用使用 `preview.db`，目录预览使用 `folder-preview.db`；旧数据库不迁入。
`LUCIDPANE_DATA_DIR` 可将预览数据隔离到指定目录。
