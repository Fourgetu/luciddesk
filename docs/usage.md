# 使用说明

先选择内容来源：**桌面分组**收纳桌面项目引用，**文件夹面板**浏览实际目录，**Everything 搜索面板**查询本机索引。三者共享外观与文件操作，但收纳引用和复制文件是不同的操作。

## 启动

使用同一次构建生成的 `lucidpane.exe` 和 `desktop_hook.dll`，将两者放在同一目录后启动主程序。获取构建产物的方法见[构建与验证](development/build.md)。

无需选择运行模式。旧参数 `--hybrid-desktop`、`--preview` 和 `--hook-desktop` 已不支持。可选启动参数见[构建指南](development/build.md)。

程序在 Windows 交互会话中运行。重复启动会显示已有实例。桌面分组需要兼容的 Explorer 组件；连接不可用时保留分组配置，文件夹和搜索面板继续运行。程序每 10 秒尝试重新连接，也可在“设置 → 关于”查看原因并手动重连。不要同时运行多个桌面接管工具。

## 字体

在“设置 → 字体”中选择本机字体，立即应用并保存；可分页浏览或恢复默认的 Microsoft YaHei UI。列表仅显示可缩放的横排字体，排除符号字体，并检查常用中文、英文字母和数字的字形覆盖。这是常用字符检查，不保证覆盖所有生僻字。

标签、文件名、菜单、重命名框、设置和搜索文字同步使用所选字体。字体被卸载或备份来自未安装该字体的电脑时，启动或恢复后会回退到默认字体；无需重新设置其他面板选项。

标题区与内容区默认显示细分隔线，可在“设置 → 面板布局 → 标题分隔线”关闭；开关会保存，收起面板时不显示分隔线。

## 标签页

桌面分组和文件夹面板支持在同一窗口内使用多个标签，也可以混合两种来源。在标题栏“…”或面板空白处右键的“标签页”子菜单中，新建桌面标签或选择文件夹建立文件夹标签。Everything 搜索面板保持独立。

- 点击圆角标签切换；右键打开菜单时不切换当前标签，关闭、重命名和左右移动作用于右键点到的标签。标签上不显示关闭、添加或翻页按钮。
- `Ctrl+T` 新建与当前来源同类的标签（文件夹标签会打开目录选择器）；`Ctrl+Tab` / `Ctrl+Shift+Tab` 循环切换；`Ctrl+W` 关闭当前标签。
- 多标签时，标签直接替代原来的标题，保持单行标题栏。宽度不足时始终显示活动标签，可通过右键菜单的“上一个标签 / 下一个标签”或快捷键切换其他标签。仅剩一个标签时恢复普通标题。按住标签拖动即可移动整个面板，轻点则切换标签；锁定时禁止拖动。标题栏空白区域也可拖动。多标签模式不显示右侧的收起和菜单按钮，右键标签可收起/展开面板，完整面板操作（设置、锁定、置顶、视图等）直接显示在同一菜单中。重命名框在当前标签位置显示。
- 每个标签保留自己的内容、视图选择，以及本次运行中的选择、滚动和文件夹导航位置。标签顺序、活动标签、名称和映射目录随工作区保存，重启后恢复。
- 窗口位置、大小、置顶、锁定、折叠和外观由整个标签组共享。后台文件夹标签暂停枚举和图像加载，切回时通过事件唤醒刷新。
- 关闭桌面标签会释放其中的桌面收纳关系；关闭文件夹标签不会删除目录或文件。原有“关闭面板”菜单关闭整个窗口及其全部标签。

后台桌面标签中的项目继续保持收纳状态。当前支持窗口内排序，暂不支持拖出标签成为独立窗口或跨标签拖放文件。

## 桌面分组

默认使用图标视图。在面板空白处右键或打开标题栏“…”菜单，选择“切换为列表视图”，以小图标和名称逐行显示；再次切换可恢复图标视图。每个分组独立保存视图选择。列表支持整行选择、键盘导航、重命名和拖放收纳，项目顺序沿用分组顺序，也可通过菜单按名称排序。

| 操作 | 方法 |
| --- | --- |
| 新建分组 | 在托盘菜单选择“新建分组” |
| 收纳图标 | 将桌面项目拖入分组 |
| 调整归属与顺序 | 在分组内或分组间拖动图标 |
| 移出分组 | 将图标拖回桌面，取消其分组归属 |
| 调整布局 | 拖动分组标题区域移动，拖动边缘缩放；移动时可吸附相邻分组与桌面边缘。左右并排时，缩放可对齐上下边缘；上下排列时可对齐左右边缘。拖离吸附范围即可自由缩放，受“自动吸附”开关控制 |
| 锁定面板 | 在面板右键菜单或标题栏“…”菜单中选择“锁定面板”，禁止移动和改名，仍可调整大小；选择“解锁面板”恢复，每个面板独立保存状态 |
| 调整外观与行为 | 打开“设置”，调整主题、材质及面板布局 |
| 重命名项目 | 选中项目后按 F2，或使用图标菜单中的重命名命令 |
| 退出 | 在托盘菜单选择“退出 LucidPane” |

重命名时 Enter 确认、Esc 取消，失去焦点时提交。输入法组词期间的 Enter 不作为提交操作。

## 文件夹面板

从托盘菜单或任意面板的菜单选择“新建文件夹面板…”，再选择源文件夹。面板显示该文件夹的直接子项，文件夹优先、按名称排列；不会把内容纳入桌面分组，也不会移动源文件。映射路径、标题、位置和外观随工作区保存。

文件夹面板默认使用列表视图，显示文件名、Windows 文件类型和本地修改时间。面板菜单中可切换列表／图标视图，每个面板独立保存选择。列表按整行选择，支持键盘导航、多选、滚动和在文件名列内重命名。

后台监听文件夹变化，新增、删除、改名后自动刷新，也可以按 F5。路径不可访问时显示提示并重试。面板菜单中可以打开源文件夹或更换映射路径；关闭面板只移除映射。

点击列表的文件名、类型、修改时间表头可排序，再次点击切换升降序；文件夹始终排在前面，排序方式会保存。

在“设置 → 文件夹面板 → 文件夹入口模式”选择打开方式，立即应用于所有文件夹面板，并在重启后保留：

- **穿透模式（默认）**：双击或选中单个文件夹按 Enter，在面板内进入子文件夹；Alt+← 或菜单“返回上个文件夹”返回。导航不改变映射根目录，重启后从根目录开始。
- **普通模式**：双击或选中单个文件夹按 Enter，在文件资源管理器中打开，面板保持当前目录。

单击仍用于选择，文件继续使用系统默认应用打开。该设置页的默认视图和默认显示列只用于新建文件夹面板。

支持多选、重命名、复制、剪切、删除、原生文件右键菜单及文件预览；Ctrl+V 粘贴到当前显示的目录。拖入真实文件会复制到当前目录，冲突由 Windows 处理；拖出使用 Windows 原生拖放。删除、改名、剪切和粘贴作用于真实文件。菜单“在资源管理器中打开”打开当前目录。文件夹面板使用设置中所选的 Peek 或 QuickLook，Peek 的文件路径入口可能显示快捷方式的 `.lnk` 后缀。

## Everything 搜索面板

在设置的“Everything 搜索”页中可浏览选择 Everything.exe，或恢复自动检测（常见安装目录及 LucidPane 同目录）。“启用搜索面板”控制全局唯一的搜索面板，关闭时保留位置、尺寸和置顶配置；重新开启恢复原配置，程序重启也会保留开关状态。旧配置中的多个搜索面板会自动保留第一个。

启动本机 Everything 1.4 或更新版本，在设置中启用搜索面板。程序自动连接正在运行的 Everything（包括命名实例），无需配置 SDK DLL。未连接或查询超时时显示提示，启动 Everything 后按 F5 重试。

初始只显示桌面固定搜索框，背景材质、圆角、边框和主题与普通面板一致。聚焦时显示强调线，右侧提供清空按钮，查询期间显示忙碌标记。输入后在下方展开结果，最多显示八行，滚动浏览并按需加载更多；底部显示结果总数及已选数量。清空输入后收回结果区域，搜索框继续保留。

每行突出文件名，下一行显示所在目录，文件和文件夹使用不同图标；长文件名尽量保留扩展名，长路径尽量保留末级目录，悬停显示完整路径。悬停与选中使用不同底色，键盘选中项带有强调标记。靠近屏幕底部时优先减少可见行数，只有连一行结果或状态提示都无法放下时才调整位置。

查询更新期间暂时保留旧结果并禁用打开操作，完成后替换，避免闪动与误打开；同一查询刷新时按文件路径恢复仍存在的选中项。没有匹配时显示调整关键词的提示，查询失败时提供重试，空结果的失败提示还提供“启动 Everything”；悬停错误说明可查看完整原因。

搜索框支持中文输入及 Everything 查询语法，例如 `ext:pdf`、`path:"E:\Project" Cargo.toml`；需要筛选时可输入 `file:` 或 `folder:`。查询在后台执行，输入更新后丢弃旧查询结果。拖动搜索框左侧图标或边缘空白处移动面板，左右边缘可调整宽度并自动保存；移动与缩放遵循“边缘吸附”设置。右键这些区域打开设置或关闭面板。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+L | 聚焦搜索框并选中查询内容 |
| Ctrl+Shift+Space（默认） | 从其他程序全局唤起搜索面板，聚焦输入框 |
| Esc（搜索框内） | 清空查询 |
| ↓（搜索框内） | 进入结果列表 |
| ↑（首个结果） | 返回搜索框 |
| F5 / 搜索框内 Enter | 刷新查询 |
| Enter / 双击结果 | 打开当前选中的第一项 |
| Ctrl+Enter | 在资源管理器中定位第一项 |
| Ctrl+A、Ctrl/Shift+点击 | 选择当前已加载的全部结果或多选 |
| Ctrl+C / Ctrl+X / Delete | 对选中结果复制／剪切／删除 |
| 设置中的预览快捷键 | 预览选中结果的第一项 |

结果右键菜单提供相同文件操作。搜索结果引用真实文件，删除会作用于原文件；关闭搜索面板不会删除文件。面板类型、位置和置顶状态随工作区保存，查询文本不保存，结果区域高度随内容自动变化。

“设置 → Everything 搜索 → 全局唤起”可录入快捷键或恢复默认；录入时 Esc 取消。只有搜索面板启用时才注册全局快捷键。被其他程序占用时显示提示并定期重试，也可换用其他组合。

## 键盘操作

先点击面板或图标使其获得焦点；快捷键仅作用于当前面板。在另一分组选择图标时，清除其他分组的选择，同一分组内仍支持多选。Ctrl+点击切换单项选择，Shift+点击选择连续范围，Ctrl+Shift+点击把连续范围加入现有选择。

| 快捷键 | 操作 |
| --- | --- |
| 方向键 | 移动选择，自动滚动使选中项可见；无选择时从第一项开始 |
| Home / End | 选择第一项 / 最后一项 |
| PageUp / PageDown | 按一页可见行数移动选择 |
| Ctrl+A | 全选当前面板的项目 |
| Shift+方向键 / Home / End / PageUp / PageDown | 从锚点扩展或缩小连续选择 |
| Ctrl+方向键 / Home / End / PageUp / PageDown | 仅移动键盘焦点，保留已有选择 |
| Ctrl+Shift+导航键 | 把连续范围加入已有选择 |
| Ctrl+Space | 切换焦点项的选择状态 |
| Space | 用设置中所选程序预览选中项（含回收站等系统图标）；多选时预览选中集合中的焦点项 |
| Enter | 打开全部选中项；双击仍打开被双击的单项 |
| F2 | 仅选中一项时重命名 |
| F5 | 刷新图标 |
| Esc | 取消拖动，或清除选择 |
| Shift+F10 / 菜单键 | 打开选中项的 Explorer 菜单；无选择时打开面板菜单 |
| Ctrl+C / Ctrl+X | 复制 / 剪切选中项 |
| Ctrl+V | 仅选中一个实际文件夹时粘贴到该文件夹，否则粘贴到桌面 |
| Delete | 调用 Windows 的删除命令，操作真实项目，确认与回收站行为遵循系统设置 |

复制、剪切、删除和右键菜单作用于全部选中项，刷新或排序后按项目身份保留选择。多选后按住任一选中图标拖动，可在普通分组内调整顺序、跨组移动或整批移回桌面；文件夹面板多选拖出使用 Windows 原生拖放。粘贴到桌面的项目先出现在桌面，需要时可拖入面板。文件操作沿用 Windows 剪贴板和冲突处理；不可用的项目命令不执行。长按打开、重命名或文件操作快捷键不会重复执行。暂不支持批量重命名和 Shift+Delete；重命名输入框内仍使用文本编辑快捷键。

在“设置 → 文件预览”中选择 Peek 或 QuickLook，所有面板只使用所选程序，不自动切换。两者分别保存程序路径，支持浏览选择和自动检测；QuickLook 可检测正在运行的商店版。默认沿用 Peek 和空格快捷键，可自定义组合或恢复默认，Esc 取消录入。快捷键仅在面板内生效，与文件操作、多选快捷键冲突时不会保存。

Peek 需要安装 PowerToys：桌面分组通过 Shell 选中项入口预览，文件夹和搜索面板通过路径启动。QuickLook 需要单独安装，通过当前用户命名管道传递文件路径或系统项目的 Shell 标识，支持回收站；未运行时尝试启动所选程序。无选择或面板折叠时不启动预览，重命名输入框中的空格仍用于输入文字。

托盘左键或键盘激活可以显示现有分组。系统可能把图标放入通知区域的折叠菜单，程序不会修改这一设置。

## 外观设置

“设置 → 面板布局”中的“图标网格缩放”按固定宽高比例调整图标占用空间，范围 50%–200%；滑块中点为默认 100%，向左缩小、向右放大；100% 对应 88 × 96 DIP，150% 对应 132 × 144 DIP。拖动实时预览，松开保存；方向键按 1% 微调，Home/End 跳到两端。“恢复默认”重置为 100%，同时恢复其他面板布局设置。图标、名称文字和网格同步缩放，重命名与拖动预览保持一致；列表视图不受影响。

在“设置 → 主题与材质”选择背景，在“面板布局”调整文字、圆角、边框和吸附。

在“设置 → 面板布局 → 面板文字”选择自动、浅色文字或深色文字。自动模式依据材质颜色选择文字明暗，“明暗底色保护”默认关闭，保留原始通透效果；需要时可开启以增加文字对比度，文字明暗选择不受影响；适用于分组、文件夹和搜索面板，不影响菜单与设置窗口。选项立即生效并保存。

在“设置 → 面板布局”中拖动滑动条调整圆角大小（0–24，默认 6，0 为直角），支持小数无级调节，也可用方向键按 0.1 微调；边框和自动吸附可独立开关，作用于所有面板，立即生效并保存。

### 纯色材质

在设置的“主题与材质”页选择“纯色”，应用不带模糊特效的背景。

- “编辑配色”打开内嵌配色页，支持预设配色、RGB 滑块和 HEX 输入。棋盘格预览显示面板实际的颜色与透明度，Esc 返回主题与材质页。
- 点击 HEX 色值可直接输入六位颜色（例如 `#24364B`），Enter 确认，Esc 取消。
- “不透明度”滑块支持 0–100%，0% 背景全透明，100% 背景不透明；文字和图标保持清晰。颜色和透明度均仅影响面板，设置窗口保持默认深浅主题底色与不透明背景。
- 点击百分比可直接输入；滑块获得焦点后，左右方向键微调，Home/End 选择两端值。
- 拖动时实时预览，松开后保存。切换到其他材质不会丢失纯色设置。
- “恢复默认”使用当前深浅主题底色和 85% 不透明度。

纯色默认值保存在 `config.toml` 的 `appearance.solid` 节；单个面板的独立覆盖值保存在工作区数据库。

### 亚克力与 Mica 强度

在主题与材质页选择亚克力或 Mica，可调整相对默认效果的强度（-50 到 +50）。中点显示“默认”，保持该材质原来的配方；负值让背景更明显，正值更接近主题底色。这是相对调节刻度，不是官方材质参数或透明度百分比。颜色随深浅主题自动变化，不开放自定义颜色。

强度仅影响面板，设置窗口保持默认效果。亚克力与 Mica 分别记住强度，支持恢复默认。拖动实时预览、松开保存；滑块获得焦点后，可用左右方向键微调，Home/End 选择两端。

Mica Alt 作为固定材质预设，不开放强度调节；之前保存的 Alt 调整值会按固定预设加载。

云母与云母 Alt 使用系统壁纸画刷和色调组合，不等同于完整原生 Mica 控制器；系统材质不可用时回退到普通背景。

## 数据与备份

默认数据目录是 `%LOCALAPPDATA%\LucidPane`：`config.toml` 保存可编辑的全局设置，`workspace.db` 保存面板和桌面布局。开发时可以通过 `LUCIDPANE_DATA_DIR` 选择独立目录，具体命令见[构建与验证](development/build.md)。

开发阶段不提供旧版迁移，不再读取 `hook-desktop.db`。手动修改 `config.toml` 后，点击“设置 → 备份与恢复 → 重新加载配置”或重启程序。“打开配置目录”可以定位文件；示例见 [config.example.toml](config.example.toml)。无效配置会报告错误，运行时保留当前有效设置；界面不会静默覆盖外部修改。

“设置 → 备份与恢复”可导出配置、选择 `.db` 备份恢复，或打开备份文件夹。导出请选择新的文件名；备份包含布局、分组归属、文件夹映射与设置，不包含真实文件。恢复前会确认并创建 `before-restore-时间戳.db`，通过完整性和格式检查后再替换配置，面板即时重新加载。

程序运行时每 5 分钟检查配置变化，有变化才生成自动快照，保留最近 10 份。自动快照位于数据目录下的 `backups` 文件夹；恢复前的备份不会随自动快照轮换删除。每份 `.db` 备份同时包含配置文件内容和布局数据。备份失败会显示在“备份与恢复”页。

每个显示器组合分别保存面板位置和尺寸。显示器或缩放变化稳定 2 秒后恢复对应布局；未见过的组合会将面板约束到可用屏幕范围。断开显示器时不会退出程序，过渡位置不会覆盖原组合的布局。实际热插拔、远程桌面与混合 DPI 仍需在相应硬件环境验证。

删除分组会解除成员归属，不删除成员文件。图标菜单里的删除、重命名等 Shell 命令会作用于真实文件，请按命令本身的含义使用。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示缺少 Hook DLL | 检查主程序与同次构建的 `desktop_hook.dll` 是否放在一起 |
| 提示数据库结构不兼容 | 改用新的开发数据目录，旧库保留不动 |
| 提示找不到 Explorer 桌面视图 | 确认 Explorer 正常运行，并从实际桌面会话启动 |
| 提示系统控件版本未经验证 | 当前版本暂不支持该系统组件；不要绕过校验，开发排查见[架构说明](development/architecture.md) |
| 空分组一直显示“正在读取桌面项目…” | 更新至 0.8.1 或更新版本；已修复空分组等待不存在的图标结果的问题 |
| 找不到分组或托盘图标 | 先检查通知区域折叠菜单，再选择“显示分组” |

系统更新后的兼容性、真实拖放、多显示器和混合 DPI 行为仍需持续验证，不能仅以启动成功判断全部交互正常。
