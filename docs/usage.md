# 使用说明

## 启动

使用同一次构建生成的 `lucidpane.exe` 和 `desktop_hook.dll`，将两者放在同一目录后启动主程序。获取构建产物的方法见[构建与验证](development/build.md)。

无需选择运行模式。旧参数 `--hybrid-desktop`、`--preview` 和 `--hook-desktop` 已不支持。可选参数 `--title <名称>` 用于指定首次创建分组的标题。

程序需要在可访问 Explorer 桌面的交互会话中运行。不要同时运行多个桌面接管工具或多个 LucidPane 实例。

## 整理分组

| 操作 | 方法 |
| --- | --- |
| 新建分组 | 在托盘菜单选择“新建分组” |
| 收纳图标 | 将桌面项目拖入分组 |
| 调整归属与顺序 | 在分组内或分组间拖动图标 |
| 移出分组 | 将图标拖回桌面，取消其分组归属 |
| 调整布局 | 拖动分组标题区域移动，拖动边缘缩放；移动时可吸附相邻分组与桌面边缘 |
| 锁定面板 | 点击标题栏展开按钮左侧的锁图标，禁止当前面板移动和改名，仍可调整大小；再次点击解锁，每个面板独立保存状态 |
| 调整外观与行为 | 打开“设置”，调整主题、材质及分组行为 |
| 圆角、边框与吸附 | 在“设置 → 面板外观”中拖动滑动条调整圆角大小（0–24，0 为直角），也可用方向键微调；边框和自动吸附可独立开关，作用于所有面板，立即生效并保存 |
| 重命名项目 | 选中项目后按 F2，或使用图标菜单中的重命名命令 |
| 退出 | 在托盘菜单选择“退出 LucidPane” |

重命名时 Enter 确认、Esc 取消，失去焦点时提交。输入法组词期间的 Enter 不作为提交操作。

### 文件夹面板

从托盘菜单或任意面板的菜单选择“新建文件夹面板…”，再选择源文件夹。面板显示该文件夹的直接子项，文件夹优先、按名称排列；不会把内容纳入桌面分组，也不会移动源文件。映射路径、标题、位置和外观随工作区保存。

后台监听文件夹变化，新增、删除、改名后自动刷新，也可以按 F5。路径不可访问时显示提示并重试。面板菜单和“设置 → 分组行为”中可以打开源文件夹或更换映射路径；关闭面板只移除映射。

双击打开文件或在资源管理器中打开子文件夹。支持多选、重命名、复制、剪切、删除、原生文件右键菜单及 Peek；Ctrl+V 始终粘贴到映射的根文件夹。拖入真实文件会复制到该文件夹，冲突由 Windows 处理；拖出使用 Windows 原生拖放。删除、改名、剪切和粘贴作用于真实文件。文件夹面板的 Peek 使用文件路径入口，快捷方式名称可能带 `.lnk`。

### 键盘操作

先点击面板或图标使其获得焦点；快捷键仅作用于当前面板。在另一分组选择图标时，清除其他分组的选择，同一分组内仍支持多选。Ctrl+点击切换单项选择，Shift+点击选择连续范围，Ctrl+Shift+点击把连续范围加入现有选择。

| 快捷键 | 操作 |
| --- | --- |
| 方向键 | 移动选择，自动滚动使选中项可见；无选择时从第一项开始 |
| Home / End | 选择第一项 / 最后一项 |
| PageUp / PageDown | 按一页可见行数移动选择 |
| Ctrl+A | 全选当前面板的项目 |
| Shift+方向键 / Home / End / PageUp / PageDown | 从锚点扩展或缩小连续选择 |
| Ctrl+方向键 / Home / End / PageUp / PageDown | 仅移动键盘焦点，保留已有选择 |
| Ctrl+Shift+导航键 | 把连续范围加入已有选择 |
| Ctrl+Space | 切换焦点项的选择状态 |
| Space | 用 PowerToys Peek 预览选中项（含回收站等系统图标）；多选时预览选中集合中的焦点项 |
| Enter | 打开全部选中项；双击仍打开被双击的单项 |
| F2 | 仅选中一项时重命名 |
| F5 | 刷新图标 |
| Esc | 取消拖动，或清除选择 |
| Shift+F10 / 菜单键 | 打开选中项的 Explorer 菜单；无选择时打开面板菜单 |
| Ctrl+C / Ctrl+X | 复制 / 剪切选中项 |
| Ctrl+V | 仅选中一个实际文件夹时粘贴到该文件夹，否则粘贴到桌面 |
| Delete | 调用 Windows 的删除命令，操作真实项目，确认与回收站行为遵循系统设置 |

复制、剪切、删除和右键菜单作用于全部选中项，刷新或排序后按项目身份保留选择。粘贴到桌面的项目先出现在桌面，需要时可拖入面板。文件操作沿用 Windows 剪贴板和冲突处理；不可用的项目命令不执行。长按打开、重命名或文件操作快捷键不会重复执行。拖动仍操作单个项目，暂不支持批量拖动、批量重命名和 Shift+Delete；重命名输入框内仍使用文本编辑快捷键。

在设置 → Peek 速览中可以启用或关闭预览、浏览选择 `PowerToys.Peek.UI.exe`，或使用自动检测（支持 PowerToys 的系统安装和当前用户安装目录）。默认启用，快捷键为空格；点击快捷键按钮后按下新组合，Esc 取消，也可恢复默认。快捷键仅在分组中生效，与现有文件操作、多选快捷键冲突时不会保存。设置即时生效并随工作区保存。

Peek 需要已安装 PowerToys；如 Peek 尚未运行，会尝试启动选定的程序。预览通过 Explorer 的 Shell 选中项入口启动，名称和系统图标行为与桌面一致；读取完成后会清除临时桌面选择，保留 pane 的选中状态。无选择或面板折叠时不启动预览，重命名输入框中的空格仍用于输入文字。

托盘左键或键盘激活可以显示现有分组。系统可能把图标放入通知区域的折叠菜单，程序不会修改这一设置。

## 数据

默认配置位置是 `%LOCALAPPDATA%\LucidPane\hook-desktop.db`。开发时可以通过 `LUCIDPANE_DATA_DIR` 选择独立数据目录，具体命令见[构建与验证](development/build.md)。

当前开发版只读取 v9 数据库，不自动迁移旧版本。遇到版本不匹配时，保留原库并改用新的数据目录。复制配置作为备份前，应先退出程序。

删除分组会解除成员归属，不删除成员文件。图标菜单里的删除、重命名等 Shell 命令会作用于真实文件，请按命令本身的含义使用。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 提示缺少 Hook DLL | 检查主程序与同次构建的 `desktop_hook.dll` 是否放在一起 |
| 提示数据库版本不支持 | 改用新的开发数据目录，旧库保留不动 |
| 提示找不到 Explorer 桌面视图 | 确认 Explorer 正常运行，并从实际桌面会话启动 |
| 提示系统控件版本未经验证 | 当前版本暂不支持该系统组件；不要绕过校验，开发排查见[架构说明](development/architecture.md) |
| 找不到分组或托盘图标 | 先检查通知区域折叠菜单，再选择“显示分组” |

系统更新后的兼容性、真实拖放、多显示器和混合 DPI 行为仍需持续验证，不能仅以启动成功判断全部交互正常。
