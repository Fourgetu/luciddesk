# 设置页公共组件

设置页继续使用现有 Rust / Direct2D 合成管线，采用 WinUI 风格的导航和设置卡片；未引入 WinUI/XAML 运行时。

## 组件与布局

`app/src/pane/settings/components.rs` 提供 Tokens、深浅主题 Palette、SettingsForm 和内容滚动视口。页面负责值与 Action 绑定，组件不访问存储。基础控件复用 controls.rs 的命中、状态和键盘逻辑。

- 内容左边界 248 DIP，右边距 24 DIP，最大宽度 1000 DIP。
- 卡片内边距 16 DIP、卡片间距 8 DIP、操作控件高度 32 DIP。
- 普通卡片至少预留 232 DIP 的尾部操作列，控件右边缘一致；说明空间不足时操作区换至下方。
- 路径使用完整内容宽度，操作按钮单独一行；说明按文本长度预留换行高度。
- 快捷键编辑区 232 DIP，恢复按钮 112 DIP，避免常用组合键截断。
- 共用分组、信息卡、开关、选项组、滑块、按钮、路径、快捷键、下拉框、导航、列表、分页、品牌卡与示意预览。

## 页面与交互

主题与材质、面板布局、文件夹面板、字体、Everything 搜索、文件预览、备份与恢复、备份记录、高级选项、配色和关于页共用这些组件。备份执行期间仍禁止重复任务，策略设置仍可操作。字体和备份分页在边界禁用按钮，翻页返回内容顶部。

所有页面共享滚动视口。侧栏及窗口标题栏固定，绘制、点击命中和焦点滚入使用同一视口边界。保留控件索引以兼容开关动画和键盘导航，支持滚轮、滚动条拖动、PageUp/PageDown 和 Tab 自动滚入。关于页图标也参与滚动及裁剪；内容未溢出时不显示滚动条。

材质预览使用带标题栏、内容层和图标的微型面板，绑定实际材质类型及强度；预览与合成器共享主题配色和强度参数。Mica 使用柔和中性底色；Mica Alt 的底色更深、壁纸色调更明显。预览使用固定示例背景，近似显示合成效果，不是 DWM 或用户桌面的实时截图。设计参考：[Microsoft Mica 文档](https://learn.microsoft.com/windows/apps/design/style/mica)。

字体候选按 GDI 字体元数据筛选：仅保留普通字重（400）、非斜体的可缩放字体，按当前界面语言校验代表字符覆盖，并按名称去重；不通过删除字体名称后缀来合并不同字体家族。

## 验证

`cargo test -p luciddesk --bin luciddesk pane::settings -- --test-threads=1`

设置 `LUCIDPANE_TEST_EXPORT_SNAPSHOTS=1` 可导出 target/settings-*.bmp。渲染测试覆盖 11 页、深浅主题、100%/150%/200% DPI、800×560 与 940×620 窗口、顶部和底部；尺寸及命中测试额外覆盖 1440 DIP 宽度。800 DIP 和底部截图分别带 `-800`、`-bottom` 后缀。

回归项包括卡片与操作区对齐、长路径不与按钮重叠、分页边界、短页面无虚假滚动、所有内容控件滚动可达，以及标题栏命中隔离。
