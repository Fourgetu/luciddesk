# 桌面同步竞争与刷新回归

验证日期：2026-09-26。验证对象为当前未提交工作区，不代表 Win10 或其他机器的兼容性认证。

## 本轮发现与修复

- 文件夹图标增量结果即使像素相同也触发刷新，并替换已有共享图像。现在比较尺寸、像素和文件类型，仅变化时更新，保持相同图像的 Arc。
- 文件夹修改时间未知时，两个 `None` 原先被当成匹配，不能可靠拒绝跨扫描的迟到结果。现在拒绝此类增量结果；完整扫描的最终快照仍能交付图像。
- 目录监听测试只消费目录快照，没有消费有限容量的图像队列。连续变更可能使后台发送阻塞，形成偶发超时。测试现在像实际界面一样消费两条队列，保留原有十秒失败期限。

桌面审计检查了成员修订键、通知在途保留和失败后调度；桌面图标检查了成员移出后的迟到结果、缓存保留和加载串行化；Hook 检查了读失败退避、写失败恢复及重入绘制门控。未发现足以在本轮更改这些恢复策略的新证据。
