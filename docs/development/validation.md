## 空闲时的重复文件访问

原后台检查每秒读取完整桌面快照，逐项打开文件获取文件 ID 和元数据。现在只读取 Explorer 项目标识与视图参数；标识或布局基线变化时才获取完整快照。

| 进程 I/O 增量 | 修改前 | 修改后 |
| --- | --- | --- |
| 读取操作 | 154 | 154 |
| 写入操作 | 0 | 0 |
| 其他操作 | 14,427 | 77 |
| 读取字节 | 3,654 | 3,654 |
| 写入字节 | 0 | 0 |
| 其他字节 | 130,970 | 1,414 |
