## 空闲时的重复文件访问

原后台检查每秒读取完整桌面快照，逐项打开文件获取文件 ID 和元数据。现在只读取 Explorer 项目标识与视图参数；标识或布局基线变化时才获取完整快照。

同一开发数据目录下，分别启动修改前后的程序，等待 3 秒后使用 `GetProcessIoCounters` 采样 10 秒：

| 进程 I/O 增量 | 修改前 | 修改后 |
| --- | --- | --- |
| 读取操作 | 154 | 154 |
| 写入操作 | 0 | 0 |
| 其他操作 | 14,427 | 77 |
| 读取字节 | 3,654 | 3,654 |
| 写入字节 | 0 | 0 |
| 其他字节 | 130,970 | 1,414 |

这些计数包含 IPC、设备及元数据访问，不等于物理磁盘读写量。采样表明重复元数据访问明显减少，不能据此宣称运行期间完全没有磁盘活动。

进一步用不打开工作区数据库的独立程序拆分 Shell 调用：预热后，每次 `CoCreateInstance(ShellWindows)` 稳定增加 22 次读取、522 字节；连续三轮一致。随后的 `FindWindowSW`、接口查询、视图参数查询、PIDL 枚举和接口释放均未增加读取。单独初始化 COM 或空闲等待也没有读取。7 次对象创建正好对应此前 10 秒样本的 154 次读取、3,654 字节，说明该样本可由重复创建 Shell COM 对象解释，并非数据库轮询。

此诊断定位到 API 调用边界，尚未确定该调用内部读取的具体文件或设备路径。系统 ETW 文件跟踪因权限不足未能启动。

随后将检查改为常驻 STA 线程复用 `IShellWindows`，每轮重新获取桌面视图，查询失败时清除对象缓存。优化版本使用同一数据目录启动后，等待 3 秒再采样 10 秒，读取、写入和其他 I/O 的操作数及字节数均为 0，错误日志为空。结果仅代表本次空闲样本。

本轮应用测试 56 项通过、2 项交互测试跳过，Shell 测试 4 项通过，工作区全部目标编译检查通过（保留已有示例未使用成员警告）。实际桌面只读测试覆盖连续复用及主动清空缓存后的重建；未重启用户的 Explorer，因此不将缓存重建测试等同于完整 Explorer 重启回归。

主程序与 Hook DLL 构建通过；应用测试 56 项通过、2 项交互测试跳过；Shell 常规测试 3 项通过。另在真实桌面单独执行以下只读检查，确认后台标识与完整快照一致：


## 菜单反复开关的资源增长

使用独立测试窗口连续打开、关闭真实菜单 120 次，每 20 次记录私有内存、进程句柄和 GUI 对象数量。关闭后检查窗口回调已释放。

| 实现 | 第 40 次私有内存 | 第 120 次私有内存 | 第 40 / 120 次进程句柄 |
| --- | --- | --- | --- |
| 每次创建图形设备 | 62,084 KiB | 74,288 KiB | 461 / 781 |
| UI 线程复用设备，菜单直接绘入交换链 | 67,248 KiB | 67,136 KiB | 687 / 687 |

修复前进程句柄每次开关约增加 4 个；修复后预热阶段保留图形资源，此后样本未呈现逐次增长。菜单移除了 GPU 读回 CPU 再上传的路径，淡入仍使用合成透明度。设备复用前会检查设备移除状态，失效时重新创建。

压力测试默认跳过，需在交互桌面中单独执行：

```powershell
cargo test -p lucidpane --bin lucidpane --offline --target-dir target\convergence-check repeated_open_close_releases_resources -- --ignored --nocapture --test-threads=1
```

阈值从预热后的样本计算，允许少量驱动缓存和辅助窗口波动。该记录不代表长时间运行、不同显卡驱动或所有系统版本的保证；批次耗时包含自动关闭定时器等待，不作为打开延迟基准。

## 相邻面板激活阴影修复

两个面板相距 5 个物理像素时，切换激活会使相邻边缘变深。现场读取发现，非客户区绘制已关闭，但窗口仍指定 `DWMWCP_ROUND`。拦截 `WM_NCACTIVATE` 和 `WM_NCPAINT` 未解决该现象；临时改用 `DWMWCP_DONOTROUND` 后，接缝区域不再随激活变化。

正式修复让面板关闭系统圆角，由合成几何裁剪保留背景圆角，并在尺寸或 DPI 改变时更新裁剪。保留 `WS_THICKFRAME` 和原有缩放命中处理，撤回无效的消息拦截。

- 主程序与 Hook DLL 构建通过；应用测试 57 项通过，1 项托盘交互测试跳过；生成绑定一致性检查通过。
- 沿用原开发数据目录重启修复版后，分别激活左右面板，对同一接缝区域进行 200 × 100 像素截图比较：20,000 个像素均一致。
- 目视检查保留圆角；实际拖动右边缘，宽度由 720 增至 760 个物理像素，再恢复原尺寸；错误日志为空。
- 以上是当前桌面环境下的验证，尚未覆盖混合 DPI 切换、全部背景材质与其他 Windows 版本。
