# 普通面板标签页

当前标签入口仅用于桌面分组，文件夹和搜索面板保持独立。桌面分组复用原有 `PanelId`，`Workspace::tab_groups` 保存成员顺序和活动 ID。一个标签组只创建一个 HWND；单标签工作区仍走原有面板路径，Everything 不参与标签组。

标签占据原有 38 DIP 标题行，不额外占用内容高度。多标签时隐藏右侧折叠和菜单按钮，相关命令放入右键菜单；保留文件夹导航按钮和可拖动的标题栏空白区域。标签与内联重命名框共享 pane 的圆角设置，编辑框贴合活动标签并采用相同的文字内边距。绘图与鼠标命中共用 `tabs::strip`，标签等分可用宽度，左右外边距相等，不为已移除的按钮预留空间；窄窗口始终显示活动标签，并通过右键菜单或快捷键访问其他标签。圆角标签仅用于切换，不附带关闭、添加或翻页按钮；管理操作统一放入右键菜单。只有一个标签时恢复普通标题。

每个标签继续独立拥有内容来源、桌面成员、列表偏好及文件夹工作线程；窗口矩形、锁定、折叠、自动隐藏、置顶和外观由活动标签同步给整组。切换前完成必要的数据读取和工作区保存，随后替换绑定 HWND 的模型及事件目标，并重新注册与当前内容来源对应的 OLE 拖放目标。后台模型保留选择和滚动，文件夹 Source 保留本次运行中的导航历史。

为兼容既有工作区中的文件夹标签，后台文件夹停止枚举与图像任务；重新激活用已有事件句柄唤醒并重新枚举。已有目录通知仍可唤醒后台线程，但不触发枚举；没有有效目录监视句柄的后台线程也无限期等待激活/退出事件。桌面收纳过滤仍读取整个工作区，因此后台桌面标签不会把项目意外释放回 Explorer。

`pane_tabs_v1` 写入既有 SQLite metadata，并与工作区同一事务提交。没有该键的旧工作区仍视为独立面板；加载会验证成员存在、组间唯一、活动成员有效且不含搜索面板。备份沿用现有 metadata 路径。此兼容性指新版本读取旧数据，不保证旧程序理解或保留新标签分组。

关闭标签只移除对应内容及缓存；关闭原有面板菜单则移除整个组。文件夹文件不会因关闭标签而删除。包含文件夹的混合组在 Explorer 重连期间仍保留窗口。

验证覆盖成员校验、存储与备份往返、复用 HWND、活动/后台关闭、选择恢复、文件夹导航与结果隔离、后台暂停及激活刷新，以及不同宽度和 DPI 的绘制/命中。窗口内容切换测试共用一个 STA 生命周期，与实际程序保持一致，避免测试间提前拆卸平台合成资源。

标签右键菜单支持“分离为独立面板”（也可从“标签页”子菜单分离当前标签）；剩余单标签恢复普通标题。分离窗口在原位置偏移 32 DIP，保留标签的选择、滚动和文件夹导航。拖动面板标题栏（包括标签区域）到另一个未锁定的普通面板标题栏时，目标标题栏高亮；松开鼠标后，源面板的全部标签按原顺序追加到目标，保留目标活动标签、窗口位置及外观。内容区不接受合并，Esc 或取消移动会清除高亮而不合并；调整大小和键盘移动不触发合并。标题栏命中按目标窗口 DPI 计算，合并候选按窗口叠放顺序选择。搜索面板不参与，锁定面板需先解锁。两种操作均保留原内容 ID 和桌面归属，并保存分组关系。

拖动合并不改变透明度。鼠标在目标标题栏停留 150ms 后，目标显示只用于绘制的合并标签预览：源标签追加到末尾，以中性灰底、灰白（浅色主题为深灰）虚线和“＋”区分；空间不足时保留目标活动标签并用数量概括待加入标签。内容区和真实分组保持不变，直到松手确认。预览成立时将源窗口裁为不可见区域，保留 HWND、鼠标控制和原生移动循环；移出或取消时恢复窗口区域。已成立的目标有 6 DIP 退出容差。合并反馈仅使用标签栏预览，不显示提示浮层。
