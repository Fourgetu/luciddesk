# 开发文档

当前主线采用视图成员过滤架构：Explorer 管理未收纳的原生桌面图标，LucidPane 自绘分组图标，通过过滤 Hook 隔离已收纳项目，并由独立 Shell 宿主提供原生菜单。旧几何方案保留在 `hook` 分支。项目处于开发期，不维护旧模式和旧数据库升级路径。

## 开始开发

1. 阅读[构建与验证](build.md)，准备 Rust 与 Windows 构建环境。
2. 阅读[架构说明](architecture.md)，确认修改所在模块的职责。
3. 涉及持久化时阅读[存储与版本约定](storage.md)；涉及绘图时阅读[绘图与绑定](rendering.md)。
4. 根据修改范围执行测试，并在[验证记录](validation.md)中区分自动检查与实际桌面结果。

## 历史资料与维护约定

[历史资料](history/README.md)保留调研来源、被替代的方案和当时的测量结果。历史页中的“当前”“已实现”等描述均以原记录时间为准，不作为新功能的验收结论。

- 介绍与使用说明放在 `docs` 根目录，避免混入 ABI、日志开关和测试夹具细节。
- 开发指南放在 `docs/development`，历史实验放在 `docs/development/history`。
- 正文使用中文；代码、API 名称、命令和必要的原始日志保持原样。
- 变更行为时同步更新当前指南；历史测量保留时间、环境和局限，不改写成新结果。
- 相对源码路径以仓库根目录为基准；Markdown 链接以所在文档目录为基准。
