更新：2026-09-14。版本 **0.9.1**，提交 **`0574300388688d429ba9ea76a122119ddacff1be`**。

本轮完成[优化方案](ablation-optimization-plan.md)的第 0 步：以当前源码重跑存储、Hook 与绘图的全部既有消融负载。生产源码与冻结快照的 SHA-256 一致，没有上一轮收尾时的源码漂移。启动时仅有空的未跟踪 `AGENTS.md`，没有未提交的生产源码修改。

两份[存储历史报告](history/storage-ablation-20260913.md)和[Hook／绘图历史报告](history/hook-render-ablation-20260914.md)保留原始数据。本页及[机器可读记录](ablation-baseline.json)作为后续优化的对照入口；本轮没有实施新的生产代码优化。

## 环境与方法

- Windows 11，系统版本 `10.0.26200`；Rust `1.98.1 (48a229cea 2026-09-01)`，MSVC x64。
- 保持原实验的 debug 构建、离线锁定依赖及原有负载；新增绘图测量使用 WARP。现有测试中显式创建硬件设备的路径保持原样。
- 存储五个版本各执行同进程三轮测量；Hook／绘图七个版本各执行三个独立进程轮次，固定随机种子为 `20260914`。
- 两组实验顺序执行，Hook／绘图的所有版本先完成构建，再开始测量，避免实验构建与本组计时重叠。
- 表内时间单位为微秒，统计方式为三轮 p50 的中位数。原始各轮 p50/p95 和工作量计数保留在 JSON；时间不作为 CI 阈值。

## 消融结论复核

| 关闭的优化 | 0.9.1 观测 | 结论 |
| --- | --- | --- |
| 配置值快速检查 | 相同配置保存从 0.2 增至 144.5 微秒，35 项测试仍通过 | 保留，功能通过不能证明没有性能代价 |
| 配置源文本检查 | 等价配置和未变工作区每 50 次调用各增加 50 次写入，现有测试失败 | 保留 |
| 两层配置检查 | 相同配置也每 50 次调用写入 50 次，现有测试失败 | 两层各有作用 |
| metadata 条件更新 | 重复保存每轮增加 50 次 SQL 行变更，现有测试失败 | 保留，行变更不等同于物理磁盘写入 |
| Hook 命中缓存 | 1,580 次命中增加 255,960 次几何查询；79 次命中的批次耗时为 79,078.1 微秒 | 保留 |
| Hook 空间筛选 | 查询计数仍为零，命中批次耗时为 1,464.8 微秒 | 保留 |
| Hook 重绘区域缓存 | 下层矩形缓存仍有效，查询计数为零；局部重绘为 931.9 微秒 | 保留；不把耗时差异外推为整个桌面的收益 |
| 文字布局缓存 | 每个 DPI 场景新增 1,200 个布局；144 DPI 的 40 个布局为 202.6 微秒 | 保留 |
| GPU 设备复用 | 30 次获取新建 30 个设备，单次获取为 2,033.8 微秒 | 保留；创建成本不等于每帧成本 |
| 跨帧纹理复用 | 每个 DPI 的 30 帧新增 720 次上传，144 DPI 绘制为 5,113.4 微秒 | 保留；时间包含重采样和上传 |

这些操作计数与上一轮一致。更新基线后，优化方案中的保留结论和实施顺序不变。

## 绘制耗时复核

主实验 192 DPI 的三轮绘制 p50 为 **668.0、2,768.7、1,641.4** 微秒，96／144 DPI 也各有一轮偏高。为核对这一波动，使用同一份基线可执行文件，单独启动三个新进程重跑测量；没有修改代码、负载或渲染后端。

| 场景 | 复核三轮 p50 | 复核中位数 |
| --- | --- | ---: |
| 96 DPI 绘制 | 2,736.5 / 552.5 / 483.0 | 552.5 |
| 144 DPI 绘制 | 2,254.2 / 563.9 / 591.5 | 591.5 |
| 192 DPI 绘制 | 1,278.6 / 663.8 / 668.1 | 668.1 |

复核说明时间存在明显轮次波动；根因尚未定位。工作量和像素没有对应变化，不能据此认定 192 DPI 出现稳定的性能回退，也不能忽略偏高样本。主实验数据完整保留，复核数字没有替换主实验；后续若要判断细小的绘制性能差异，应先改善计时稳定性、增加原始样本，并补测 release／硬件后端。
