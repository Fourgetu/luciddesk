# 存储与版本约定

## 当前格式

当前 schema 为 v9，数据库文件名为 `hook-desktop.db`。默认目录是 LocalAppData 下的 `LucidPane`；设置 `LUCIDPANE_DATA_DIR` 可将开发配置隔离到其他目录。

| 表 | 内容 |
| --- | --- |
| `metadata` | schema 版本与全局外观默认值 |
| `panels` | 分组标题、几何、折叠、锁定与背景 |
| `panel_theme` | 分组主题 |
| `panel_layer` | 置顶设置 |
| `panel_behavior` | 自动收起行为 |
| `desktop_items` | Shell 身份与桌面／分组位置 |

已移除来源模式、旧路径成员列表和未使用的自定义标题图标字段。成员归属统一通过 `DesktopPlacement` 保存。

## 打开与保存

空数据库在事务中创建当前表结构。已有数据库必须匹配当前版本，否则返回错误，不执行历史升级，也不自动删除数据。格式版本正确不代表任意损坏表结构都能自动修复，读取错误会向上传播。

保存工作区时在一个事务中替换快照。文件身份、分组成员、主题和行为设置一同持久化；事务失败不会提交部分新状态。

## 开发期变更原则

1. 只维护当前格式；不为未发布的旧开发版增加长期升级分支。
2. 删除或改变持久化字段含义时递增版本，并同步初始化 SQL、读写逻辑与回归测试。
3. 使用新目录验证不兼容变更，保留需要追溯的旧库；不要把重建开发数据等同于删除用户文件。
4. 保留当前格式重新打开、完整往返、快照替换和拒绝旧版本不写入的测试。

数据库中的分组归属与文件系统操作是不同层次：收纳只改变引用；Shell 重命名和删除命令另由 Shell 执行。
