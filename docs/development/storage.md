# 存储与版本约定

## 当前格式

当前 schema 为 v10，数据库文件名为 `hook-desktop.db`。默认目录是 LocalAppData 下的 `LucidPane`；设置 `LUCIDPANE_DATA_DIR` 可将开发配置隔离到其他目录。

| 表 | 内容 |
| --- | --- |
| `metadata` | schema 版本与全局外观默认值 |
| `panels` | 分组标题、几何、折叠、锁定与背景 |
| `panel_theme` | 分组主题 |
| `panel_layer` | 置顶设置 |
| `panel_behavior` | 自动收起行为 |
| `desktop_items` | Shell 身份与桌面／分组位置 |
| `monitor_layouts` | 显示器组合、面板 ID 与物理像素几何 |

已移除来源模式、旧路径成员列表和未使用的自定义标题图标字段。成员归属统一通过 `DesktopPlacement` 保存。

## 打开与保存

v8 升级保留桌面身份、分组归属、布局、主题和行为；旧来源字段中的文件夹映射转换为当前 metadata 键，再移除已废弃的来源与标题图标列。若旧 `panel_items` 仍有路径集合，因当前桌面归属模型不能完整表示，拒绝自动迁移并保留原库，避免静默丢失内容。升级前的独立备份保留完整旧结构。

空数据库在事务中创建当前表结构。v8/v9 库先通过 SQLite 在线备份保存原库，再在事务中新增显示器布局表并升级为 v10；未知版本拒绝读取。格式版本正确不代表任意损坏表结构都能自动修复，读取错误会向上传播。

配置导出使用 `VACUUM INTO` 生成一致的独立数据库。恢复时以只读方式打开来源，在内存副本中执行升级、完整性、外键和工作区检查，再通过 SQLite Backup API 原子替换当前库。应用在恢复前另存当前配置，恢复后重新加载窗口和设置。

保存工作区时在一个事务中替换快照。文件身份、分组成员、主题和行为设置一同持久化；事务失败不会提交部分新状态。

`metadata.pane_options` 保存全局圆角半径、边框和自动吸附开关，按该顺序使用 `7|true|true` 形式。圆角范围为 0–24 DIP，0 表示直角；默认半径为 7，边框与吸附默认开启。此前圆角开关值 `true` / `false` 分别读为 7 / 0，下次保存写入数值。值无效时返回读取错误。选项独立于面板列表保存，没有面板时也会保留，新建面板使用当前全局选项。

## 开发期变更原则

`panel_folder_view:<面板 ID>` 保存文件夹显示方式（`list` 或 `icons`）；缺失时默认列表。随文件夹映射在同一事务中保存和删除。

`panel_folder_sort:<面板 ID>` 保存排序列与方向，如 `2:desc`；列为名称 0、类型 1、修改时间 2。目录导航历史仅在运行时保留。`search_hotkey` 保存全局搜索快捷键的虚拟键码与修饰位，如 `32:3` 表示 Ctrl+Shift+Space。快捷键只在搜索面板启用时注册，注册冲突不会接管其他程序的绑定。

`metadata` 中的 `panel_folder:<面板 ID>` 保存文件夹面板的源路径。没有该键的面板仍是桌面分组。每次保存工作区时，在同一事务中重建这些映射键；关闭面板会移除对应键。文件夹子项由运行时枚举，不写入 `desktop_items`，也不参与桌面图标隐藏或归属协调。v8/v9 库升级后保留原映射；目录不可访问时保留映射，交由运行时显示错误并恢复。

1. 维护已知 v8/v9 到 v10 的无损升级；不推测更早开发版的格式。
2. 删除或改变持久化字段含义时递增版本，并同步初始化 SQL、读写逻辑与回归测试。
3. 使用新目录验证不兼容变更，保留需要追溯的旧库；不要把重建开发数据等同于删除用户文件。
4. 保留当前格式重新打开、完整往返、快照替换和拒绝旧版本不写入的测试。

数据库中的分组归属与文件系统操作是不同层次：收纳只改变引用；Shell 重命名和删除命令另由 Shell 执行。
