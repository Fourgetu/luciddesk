# Win10 闪烁对照测试

## Explorer 退出错误

若此前退出时 Explorer 重启，不必再次复现。运行 `Collect-Explorer-Error.cmd`，
它只读取最近 7 天内与 explorer.exe、luciddesk.exe、lucidpane.exe 有关的应用错误事件和已有 WER 文本报告，保存为 `explorer-errors.txt`。
请把采集脚本放在测试版 exe 同目录，以便同时记录构建信息和 exe / DLL 的 SHA256。报告可能包含本机路径及用户名。
不会启动、退出或重启任何程序，也不会自动上传。请回传该文件和发生退出问题时的渲染日志。

这是定位问题用的便携包，尚未确认修复了闪烁。

每次先从托盘退出 LucidDesk，再启动下一项；否则单实例保护会让新启动立即退出。
使用同一份 data、相同材质、相同面板，依次双击下面的启动文件，每项点击面板并拖动约 10 秒。

| 启动文件 | 唯一改变 | 日志 |
| --- | --- | --- |
| A-current.cmd | 保持当前渲染路径 | render-A.log |
| B-shared-tree.cmd | 面板背景和内容使用同一合成树 | render-B.log |
| C-no-backdrop.cmd | 关闭系统模糊背景；云母和亚克力暂显示不透明主题底色 | render-C.log |

C 不修改保存的材质选择；纯色和半透明材质维持原行为。重新从 A 启动即可恢复原背景。
这些环境变量仅对本次启动有效。直接运行 luciddesk.exe 仍使用正常路径。

请反馈 A、B、C 分别是否闪，以及只有背景闪还是图标文字也闪，并附上三个日志。
日志记录系统版本、构建、材质类型、窗口消息、透明度变更和合成错误，不记录文件名、面板标题或文件内容。
每次启动覆盖对应日志，最多记录 4000 行，不会自动上传。
